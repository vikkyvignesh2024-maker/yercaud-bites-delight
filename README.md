# Yercaud Bites Website

Create a premium, modern, fully responsive website for my food brand:

BRAND NAME:

MP Snacks & Bites

LOCATION:

Yercaud, Tamil Nadu, India — a beautiful hill station known for its green mountains, lake, forests and cool climate.

BRAND STYLE:

Premium hill-station snack café with a warm, welcoming, local South Indian feel.

IMPORTANT:

Use the uploaded MP Snacks & Bites logo as the main brand identity/reference.

Do not redesign the logo.

Do not use React.

TECH STACK:

- HTML5

- CSS3

- Bootstrap 5

- Vanilla JavaScript

- Bootstrap Icons or Font Awesome

- Fully responsive for mobile, tablet and desktop

- Clean semantic HTML

- Well-organized CSS and JavaScript

- No React

- No unnecessary frameworks

Use a premium natural color palette throughout the website:

Forest Green: #164A32

Forest + Mist + Warm Tea + Fresh Snacks + Yercaud Hills.

Create a premium food website inspired by a cozy hill-station café.

Use:

- Large beautiful food photography

- Rounded cards

- Soft shadows

- Cream backgrounds

- Forest green sections

- Warm orange CTA buttons

- Elegant typography

- Smooth hover animations

- Subtle scroll animations

- Glass/blur effects only where appropriate

- Premium spacing

- Large visual sections

- Beautiful food cards

- High-quality responsive layout

Avoid:

- Cheap-looking colors

- Excessive gradients

- Overcrowded UI

- Generic restaurant templates

- Too many animations

- React

- Dark website as the primary theme
